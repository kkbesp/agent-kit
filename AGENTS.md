# agent-kit — правила разработки репозитория

Публичный репозиторий: всё, что здесь лежит, увидят стажёры и посторонние.

## Структура

- `rules/AGENTS.md` — общие правила агента; единственный источник, Claude получает его импортом, Codex — копией блока при установке.
- `plugins/agent-kit/` — Claude-плагин: `skills/` (они же ставятся в Codex ссылками), `agents/`, `hooks/`.
- `codex/agents/*.toml` — те же агенты для Codex; текст инструкций совпадает с `plugins/agent-kit/agents/*.md`.
- `skills.json` — сторонние скиллы по группам; `install.mjs` — установщик; `settings/claude.json` — сливаемые настройки.
- `plugins/agent-kit/skills/kickoff/templates/project/` — шаблон проекта, включая навигатор `scripts/roadmap.mjs`.

## Правила

- Никаких личных данных: имён, путей `/Users/...`, рабочих сервисов, токенов, приватных логов. Перед коммитом: `rg -i '/Users/|@gmail|token|secret'`.
- Изменил агента — обнови и `.md`, и `.toml`. Изменил скилл метода — сверь README и `rules/AGENTS.md`.
- Новый сторонний скилл — только с проверкой `npx skills add <repo> -l` и точным именем; копии чужих скиллов не класть.
- Установщик меняет чужие файлы: любое изменение `install.mjs` — тест в `tests/install.test.mjs` и прогон в изолированном HOME (`--home=<временный каталог>`).
- Проверки перед коммитом — команды из раздела «Разработка» в README.

## Частые ошибки

- Скилл ссылается на инструмент, которого у стажёра нет (личный браузер, платный API) → инструменты указывать с вариантами и общим способом → поиск названий личных сервисов перед коммитом.
