## Темп и качество

- Дешёвая обратная связь первой: формат, линт, типы затронутого; затем профильный тест; полный набор — на интеграции.
- Тест защищает реальный риск. Деньги, права, сессии — с отрицательными сценариями.
- UI готов после просмотра desktop и mobile; PDF — после просмотра каждой страницы.
- Один срез → проверка → коммит → одна строка статуса в карточке.
- Временное — в `.artifacts/`; секреты и личные данные не коммитить.

## Частые ошибки

Формат: что нельзя → как правильно → чем проверить. Новая строка — после подтверждённого замечания владельца (skill `lesson`). Повтор закрепляется проверкой, а не второй фразой.
