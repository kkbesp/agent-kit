# Уроки

Опыт прежних версий, конкурентов и этого проекта. Источник подтверждённых ошибок и удачных решений, а не архитектуры для копирования. Только обезличенные выводы, без приватных логов и абсолютных путей.

Форма: **наблюдение** (что произошло, где и как проверено; отличать факт от гипотезы) → **вывод** (что сохраняем, что исправляем) → **решение** (решение N, карточка) → **проверка** (как карточка доказывает, что ошибка не повторилась).
